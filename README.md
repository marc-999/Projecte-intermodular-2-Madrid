## Sobre el proyecto

Proyecto intermodular del grupo Madrid (2º ASIX): diseño, despliegue y documentación de la infraestructura de red y servidores de la sede de Madrid.

- **Red:** switch Cisco segmentado en cuatro VLAN (210, 220, 230 y 299), con acceso de gestión por Telnet.
- **Virtualización:** hipervisor Proxmox VE sobre un servidor físico, con máquinas virtuales Ubuntu Server y Linux Mint.
- **Servicios:** Windows Server 2025 con almacenamiento en cuatro discos y servicio DHCP para la VLAN 210.
